# 03. 홈택스 / 위택스 전자신고 자동화 경로 조사

- 작성일: 2026-09-26
- 대상: MIN TAX OPS (위멤버스 ↔ MIN TAX OPS ↔ WEHAGO 미들웨어)
- 범위
  - (a) 원천세(원천징수이행상황신고서), 간이지급명세서(근로·사업·기타), 지급명세서, 지방소득세(특별징수분)를 제출하는 공식 API가 있는지, 아니면 변환파일(전산매체) 업로드만 가능한지
  - (b) 위택스 지방소득세 특별징수 신고와 홈택스 연계 방식
  - (c) 2026년 현재 적용되는 제출주기·신고기한·세율·계산 규칙
- 근거 등급 표기
  - **[공식]** 법령, 행정규칙, 국세청·행정안전부·지자체 공식 문서. 원문(법령 미러에서 가져온 원문 조각 포함)을 확인한 것
  - **[공식(검색 요약)]** 출처 URL은 공식 사이트이지만, 이번 세션에서는 원문을 열지 못하고 **검색엔진 요약으로만** 확인한 것
  - **[보도]** 언론 기사
  - **[커뮤니티]** 블로그, 업체 도움말, 업체 개발문서, GitHub 코드, 앱 리뷰
  - **[추론]** 위 자료를 바탕으로 한 작성자 추론(사실로 확인된 것이 아님)
- **조사 방법상 한계(중요)**
  1. 이번 세션에서는 이그레스 정책 때문에 **WebFetch가 모든 대상 도메인에서 차단**되었다(`EGRESS_BLOCKED`). 차단된 도메인은 `nts.go.kr`, `law.go.kr`, `hometax.speedycdn.net`, `taxtimes.co.kr`, `casenote.kr`, `korea.kr`, `clobe.ai`, `wehagohelp.zendesk.com`, `ai.bznav.com`, `ujuni.com`, `welfarehello.com`이다. 그래서 국세청 전산매체 제출요령 PDF를 포함해 **원문 문서를 한 건도 열람하지 못했다.**
  2. 웹 검색은 조사 도중 **세션 한도(200회)에 도달해 더 이상 쓸 수 없었다.**
  3. 이를 보완하려고 **GitHub 코드 검색**으로 법령·행정규칙 Markdown 미러의 원문 조각을 확인했다. 사용한 미러는 `genonai/ADMRUL`(행정규칙)과 `wellsa-ai/law-kr`(법령, 2026-09-15 개정분까지 반영된 것으로 보임)이다. 두 미러 모두 **비공식 사본**이므로 최종 확정 전에 law.go.kr 원문으로 다시 확인해야 한다.
  4. 2026-09-26 팩트체크에서 법령 조문을 `legalize-kr/legalize-kr` 미러(law.go.kr 수집본, 커밋 `3969940b`, 소득세법은 2026-09-08 공포본)로 다시 대조했다. 이 미러에서 확인한 항목은 등급을 **[공식(법령 미러 원문)]**으로 올렸다. 변경 내역은 맨 끝 「팩트체크 결과」에 있다. 이 미러도 비공식 사본이다.

## 1. 요약

1. **공식 "신고 제출 API"는 확인되지 않았다 → LIVE 연동은 NOT AVAILABLE**
   - 국세청 행정규칙인 「홈택스 이용에 관한 규정」 제12조는 전자신고 방식을 세 가지로만 정한다: **① 신고서 작성 방식 ② 신고서 변환 방식(파일) ③ 신고서 확인 방식**. API 방식은 규정되어 있지 않다. [공식]
   - 공공데이터포털에서 국세청이 제공하는 OpenAPI는 **사업자등록 진위확인·상태조회 정도**라는 업체 분석이 있다. [커뮤니티]
   - 국세청은 2025년에 스크래핑을 대체할 **Open API ISP(분석·설계)**를 추진했다. [보도] 다만 **신고 제출 API가 여기에 포함되는지는 미확인**이다.
2. **현실적인 자동화 경로는 "변환(파일) 신고"다**
   - 흐름: 회계·급여 프로그램(WEHAGO 등)이 전자신고 파일을 생성 → 홈택스 `원천세 > 파일 변환신고(회계프로그램)`에 업로드 → 비밀번호 입력·형식검증 → `전자파일 제출하기` → 접수증·납부서 출력. [커뮤니티(검색 요약)]
   - 지급명세서와 간이지급명세서는 홈택스 `지급명세서 > 변환제출방식`으로 제출한다. [커뮤니티]
3. **파일 규격**
   - 국세청은 「지급명세서 전산매체 제출요령」과 「간이지급명세서 전산매체 제출요령」을 자료실에 게시한다. [공식(검색 요약)]
   - 근로소득 지급명세서가 "A~G 7종 레코드"라는 검색 요약은 **미확인(UNVERIFIED)**이다. 레코드 종류와 개수는 원문으로 확인하기 전까지 가정하지 않는다.
   - 두 문서 모두 **원문(레코드 길이, 필드별 byte 위치, 인코딩)은 이번 세션에서 열람하지 못했다 → 미확인**.
   - **원천징수이행상황신고서 전자신고 파일 레이아웃은 공개 문서로 확인하지 못했다 → 미확인(UNVERIFIED).**
4. **위택스(지방소득세 특별징수)**
   - 법적 근거: 지방세법 제103조의13 ①·②에 따라 **원천징수 소득세의 10%**를 특별징수하고, **징수일이 속하는 달의 다음 달 10일**까지 납부한다. 소득세를 반기납부하면 같은 조 ② 단서에 따라 반기 마지막 달의 다음 달 10일까지 납부할 수 있다. [공식(법령 미러 원문)]
   - 위택스 신고 경로는 `신고 → 지방소득세 특별징수`이며 세 가지 방식이 있다: **한건신고**, 그리고 사업장이 여러 지자체에 있을 때 쓰는 **엑셀파일신고 / 회계파일신고**. [공식-지자체 안내]
   - 홈택스 → 위택스 **원클릭 연계**
     - 종합소득세: 공식으로 확인했다.
     - **원천세 신고 후 연계**: 커뮤니티·동영상에서 관찰한 수준이며, **2025~2026년 현행 메뉴명과 동작은 미확인**이다.
5. **근로소득 간이지급명세서(상용근로)**
   - **2026년에는 반기 제출**이다: 1~6월 지급분은 7월 말일까지, 7~12월 지급분은 다음 해 1월 말일까지.
   - 월별 제출 시행일은 **2026-01-01에서 2027-01-01로 1년 유예**되었다. 소득세법 부칙 <제19196호, 2022.12.31> 제1조 제5호와 제6조 ②·⑤가 2025.12.23 개정으로 바뀌었다. [공식(법령 미러 원문)]
   - 2027년 지급분(반기납부자는 2028년 지급분까지)은 **종전 반기 기한까지 제출하면 미제출가산세를 면제**하는 한시 특례가 있다(소득세법 제81조의11 ③ 1호). [공식(법령 미러 원문)]
   - 2026-09-08 공포본 소득세법에는 추가 유예가 없다. 다만 **2026년 세법개정안(2026년 하반기 국회 심의)에 재유예가 들어 있는지는 미확인**이다.
6. **매월 제출 대상**(지급일이 속한 달의 다음 달 말일까지)
   - 사업소득 간이지급명세서와 일용근로소득 **지급명세서**: 2021-07 지급분부터 매월 제출한다.
   - 인적용역 기타소득 간이지급명세서: 2024-01 지급분부터 매월 제출한다.
   - 두 간이지급명세서를 제출하면 제출한 부분은 **연간 지급명세서를 제출한 것으로 본다**(소득세법 제164조 ⑦). 연말정산 사업소득은 제외된다. [공식(법령 미러 원문)]
   - 상용근로 간이지급명세서의 2026년 지급분은 **기한 후 3개월 이내**에 내면 가산세 0.125%다(종전 규정). 사업·기타 간이지급명세서는 1개월 이내다. [공식(법령 미러 원문)]
7. **원천세 신고·납부 기한**
   - 원칙: **다음 달 10일**(소득세법 제128조 ①).
   - 반기납부 특례: 직전연도 상시고용인원 **20명 이하**이고 금융·보험업이 아니며 **승인을 받은** 사업자가 대상이다. 종교단체와 국세청장 지정분도 포함된다. 상반기분은 **7월 10일**, 하반기분은 **1월 10일**까지 납부한다(소득세법 제128조 ②, 시행령 제186조). [공식(법령 미러 원문)]
   - 반기납부 대상자라도 다음 원천세는 반기납부에서 **제외**되어 다음 달 10일까지 내야 한다(제128조 ② 각 호): 법인세법 제67조에 따른 소득처분 상여·배당·기타소득분, 국제조세조정법에 따른 배당 처분분, 제156조의5 ①·②분. [공식(법령 미러 원문)]
8. **세율·계산**
   - **사업소득**: 3%이고, 지방소득세 0.3%를 더해 **3.3%**다(소득세법 제129조 ① 3호, 지방세법 제103조의13 ①). [공식(법령 미러 원문)]
   - **일용근로**: 원천징수세액 = (일급 − 150,000원) × 6% × (1 − 55%)이며, 실효세율은 **2.7%**다(소득세법 제47조 ②, 제129조 ① 4호, 제59조 ③, 제134조 ③). [공식(법령 미러 원문)]
   - **소액부징수**: 원천징수세액이 **1,000원 미만**이면 징수하지 않는다. 일용근로 임금을 일괄지급할 때는 일별 세액을 **합계**한 금액으로 판단한다.
   - 소액부징수 예외: 인적용역 사업소득은 **2024-07-01 지급분부터 소액부징수를 적용하지 않는다**(시행령 제149조의3). 이자소득도 예외다. [공식]
   - 지방소득세 = 소득세의 **10%**다.
9. **권고**
   - 원천세·간이지급명세서·지급명세서·지방소득세 모두 **FILE BASED**를 주 경로로 둔다. 파일은 WEHAGO가 생성하고 사람이 업로드한다.
   - 개발·테스트는 **MOCK**으로 한다.
   - 홈택스·위택스 **RPA는 보류**한다(스크래핑 규제 리스크는 `02-wemembers.md` 참조).
   - MIN TAX OPS가 홈택스 변환파일을 **직접 생성하는 것은 권장하지 않는다**. 규격 원문을 확보하지 못했고, 암호화 방식도 미확인이기 때문이다.

### 4.2 권장 파이프라인 [추론]

```
위멤버스(홈택스 자료 수집) ──(엑셀/ZIP)──▶ MIN TAX OPS
                                            │  ① 소득자·지급내역 정규화
                                            │  ② 세액 재계산·검증(4.4 규칙)
                                            │  ③ 기한 캘린더·반기납부 여부 관리(4.3)
                                            ▼
                                  WEHAGO(급여/원천세 입력·마감)
                                            │  ④ 전자신고 파일 생성(WEHAGO 기능)
                                            ▼
                      [사람] 홈택스 변환신고 / 변환제출 → 오류검증 → 제출
                      [사람] 위택스 특별징수 신고(한건/회계파일/엑셀파일)
                                            │
                                            ▼
             접수증·납부서 회수(위멤버스 ZIP 또는 수동 업로드) → MIN TAX OPS 대사
```

- **MIN TAX OPS가 할 일**: 계산 검증, 기한·누락 관리, 제출 증빙(접수증) 보관, 금액 대사, 체크리스트
- **MIN TAX OPS가 하지 않을 일**: 홈택스·위택스 전송, 변환파일 생성(U1·U2 해소 전까지)
- 「홈택스 이용에 관한 규정」 제13조에 따라 **접수증 보관은 의무**다. 그러므로 제출 건마다 `접수증 첨부 여부`를 완료 조건으로 삼는다.
- 같은 규정 제15조에 따라 **재전송하면 최종분이 유효**하다. 그러므로 제출 패키지를 `(사업자, 세목, 귀속연월, 제출차수)`로 버전 관리하고, 최신 접수분을 정본으로 표시한다.

### 4.4 계산 테스트 벡터(WEHAGO 결과와 대조해 확정할 것)

| 케이스 | 입력 | 기대 소득세 | 기대 지방소득세 | 근거 |
|---|---|---|---|---|
| T1 일용 1일 | 일급 200,000 | (200,000−150,000)×6%=3,000 → ×45% = **1,350** | **135** (합 1,485) | G3, G8 |
| T2 일용 소액부징수 | 일급 187,000 | 37,000×2.7% = 999 → **0**(1,000 미만) | **0** | G4, G8 |
| T3 일용 일괄지급 | 일급 180,000 × 5일을 한 번에 지급 | 일별 30,000×2.7%=810, 합계 **4,050**(≥1,000이므로 징수) | **405** | G6, G7 |
| T4 사업소득 | 1,000,000 | **30,000** | **3,000** | G1, G2 |
| T5 인적용역 사업소득 소액 | 20,000(2024-07-01 이후 지급) | 600 → **징수**(소액부징수 배제) | 60 | G5 |

### 4.6 데이터 모델 · 운영 요구사항 [추론]

- `FilingPackage`: 사업자, 세목(`WITHHOLDING`/`SIMPLIFIED_WAGE`/`SIMPLIFIED_BIZ`/`SIMPLIFIED_OTHER`/`DAILY_WORKER`/`LOCAL_SPECIAL`), 귀속·지급연월, 제출차수, 생성원(WEHAGO), 파일 해시, 제출자(사람), 접수번호, 접수증 파일, 상태(`READY`→`SUBMITTED_BY_HUMAN`→`RECEIPT_ATTACHED`→`RECONCILED`)
- `LocalTaxAllocation`: 사업장별 지자체와 특별징수액. 여러 지자체에 사업장이 있으면 위택스 회계·엑셀 파일신고를 쓰도록 안내한다(D3).
- `ClientProfile.semiannualApproved`: 반기납부 승인 여부와 승인 반기(F3). 직전연도 상시고용인원이 20명을 넘으면 경고한다.
- 거래처별 `localTaxChannel`: `WETAX` 또는 `SEOUL_ETAX`(U6)
- 규격 문서 버전 관리: `docs/specs/nts/{귀속연도}/…pdf`. 원문 확보 전에는 레이아웃 코드를 만들지 않는다(C3, U2).

### 4.7 후속 조치(사람이 수행)

1. 홈택스 자료실에서 다음 문서의 최신판을 다운로드해 `docs/specs/`에 보관한다(이번 세션에서는 차단됨): 「지급명세서 전산매체 제출요령」, 「간이지급명세서 전산매체 제출요령」, 원천징수이행상황신고서 작성요령. 원천세 전자신고 파일 레이아웃 문서가 따로 있는지도 확인한다.
2. WEHAGO에서 실제로 생성한 **원천세 전자신고 파일, 간이지급명세서 파일, 일용 지급명세서 파일, 지방소득세 특별징수 출력물**의 샘플(마스킹본)을 확보한다.
3. 위택스 `신고 → 지방소득세 특별징수` 화면에서 **회계파일신고 규격과 엑셀 양식**을 확보한다. 원천세 신고 후 홈택스 → 위택스 연계 버튼이 지금도 있는지 화면으로 캡처한다.
4. 2026년 세법개정 국회 통과 결과(2026-12 예상)를 확인해 **U7(2027 월별 전환)**을 확정한다.
5. G3·G4·U11 조문 번호는 legalize-kr 법령 미러로 확인했다(팩트체크 결과 참조). 최종 배포 전에 law.go.kr 원문과 한 번 더 대조하고, 계산 단계별 끝수 처리(U12)를 국세청 원천징수 안내 또는 WEHAGO 결과로 확정한다.
